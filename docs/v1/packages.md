# `.star` Packages

> **Status: Draft**

`.star` is the Lodestar content package format. A package is intended to carry portable Lodestar content and the metadata and resources needed to interpret it.

The extension is settled; the container technology, manifest fields, directory layout, dependency model, signing, compression, canonicalization, and compatibility rules are not yet specified. The schemas in `schemas/v1` are placeholders and do not imply those decisions.
