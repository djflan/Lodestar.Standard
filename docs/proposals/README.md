# Lodestar Standard Proposals

Proposals discuss material changes before they become normative. Copy [template.md](template.md), assign a descriptive filename, and open review. A proposal MUST identify affected v1 chapters/schemas/contracts, compatibility impact, alternatives, migration, and which existing requirements remain unchanged.

Statuses are Proposed, Under Review, Accepted, Rejected, or Withdrawn. Acceptance records consensus but does not itself amend the Standard: normative files, schemas, examples, and contracts must be updated together. Breaking interoperability changes target a future Standard version; compatible clarification/finalization may target v1 Draft.

Open questions belong in [the v1 tracker](../v1/decisions-and-open-questions.md) until a proposal resolves them.
